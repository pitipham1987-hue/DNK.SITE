# Triage Labels

Các skill nói chuyện với nhau bằng năm vai trò triage chuẩn (canonical). File này ánh xạ các vai trò đó tới các chuỗi nhãn thực tế được dùng trong issue tracker của repo này.

| Label trong mattpocock/skills | Label trong tracker của chúng ta | Ý nghĩa                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer cần đánh giá issue này  |
| `needs-info`               | `needs-info`         | Đang chờ người báo cáo cung cấp thêm thông tin |
| `ready-for-agent`          | `ready-for-agent`    | Đã được đặc tả đầy đủ, sẵn sàng cho một agent AFK  |
| `ready-for-human`          | `ready-for-human`    | Cần con người triển khai            |
| `wontfix`                  | `wontfix`            | Sẽ không được xử lý |

Khi một skill nhắc tới một vai trò (ví dụ: "apply the AFK-ready triage label"), hãy dùng chuỗi nhãn tương ứng từ bảng này.

Chỉnh sửa cột bên phải để khớp với bất kỳ từ vựng nào bạn thực sự đang dùng.
